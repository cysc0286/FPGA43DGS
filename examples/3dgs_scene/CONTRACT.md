# 万级以上真实场景渲染测试

本轮用官方 train/iteration_7000 的真实参数建立完整图像负载。规模为 10,000、50,000、100,000、559,263 个不同 Gaussian，不复制点，不重训练。使用固定种子的嵌套子集；删点后的图像可能有空洞，不能当作压缩模型质量成果。完整模型作为主要图像展示与性能结果。

官方 CUDA 负责投影、SH、Tile 分组与排序并生成 PC Golden；板端输入是完整图像的投影属性和有序列表，实际执行所有像素的 Gaussian 求值、exp、阈值处理与颜色合成。板端时延从驻留投影输入到完整输出，包含所需定点打包和 FPGA 交接，不含 GPU 预处理、文件加载、SSH 或显示。不是 Camera Pose→Framebuffer 全阶段部署。

比较 FP32 CPU 单/多线程、冻结定点合成 CPU 单/多线程和 CPU 求值+GSB1 合成。CPU 版本互相及 FPGA 版本逐字段核对；对官方 CUDA 继续沿用 RGB 最大 1e-4、平均 1e-5、T 最大 1e-5 和 last 精确的门槛。失败不得隐藏或事后放宽。FPGA 仍只有 256 条物理批容量，场景规模和单次硬件批大小分别报告。

记录模型点数、进入画面的不同点数、实际访问/贡献的不同点数、Tile 重复项数、求值/跳过/贡献次数和提前终止像素数，避免用输入点数冒充有效工作量。记录每轮原始时延、CPU 时间、线程数、峰值 RSS、传输和硬件周期；重复次数依首轮实际耗时制定，样本不足时不把尾分位数当作稳定结论。

4 Gaussian 小闭环只保留为历史回归，不再作为场景性能代表。原 BOOT、旧实验、模型和 Golden 不覆盖。
