## 先解决的架构问题

1. 输入已排序 Gaussian 的二维均值、conic、opacity、RGB。FPGA 内部求值、alpha 筛选、终止和合成；CPU 不展开 Gaussian–pixel 命令。
2. 使用厂商 SDK `MemChunk.write/read` 与用户侧 512 位 PL-DDR 接口；禁止直接 `/dev/mem` 写。完整数据块一次提交，寄存器只承载描述符和状态。
3. 两个独立所有权缓冲，块预取与计算重叠，CTU/FIFO/VRU 背压；计数器证明交叠，不能只用“双缓冲”名称声称流水。
