# 换视角渲染：资源使用与论文机制计划

2026-09-30。范围是场景常驻后的相机输入到完整 RGB 帧，不含视频、重建、
训练或 MVSplat。用户暂时没有板卡，本轮不访问设备。已有资源以降低帧延迟
为先，不再人为给前端留出一半资源；综合能放下、真实布线及最终上板结果
仍是不同阶段。满占用不等于高吞吐，新增逻辑不能堵住原有数据通路。

## 已做优化是什么

原四路 VRU 每次处理一个高斯在一个子块内的 16 个像素。像素循环虽然 II=1，
但每次调用要填充、排空长流水线，还要先加载、后写回像素状态。对于覆盖
多个子块的高斯，重复短调用会造成大量空拍。

`grouped-registers` 把同一个高斯在同一路上的最多四个子块合成一次 64 像素
调用，直接更新常驻状态。四条参数记录改用寄存器，避免浅而宽的数据浪费
BRAM 端口和容量。高斯深度顺序、逐像素 FP16 算术、裁剪和提前终止保留。
这是本项目的数据调度改进，不是新增无排序公式，也不声称出自某篇论文。

上轮同输入、三 Tile 的 DMA/CDC RTL mode 2 周期 4861→3442（−29.19%）；
全板帧延迟没有新测。HLS FF 64227→92935，BRAM_18K 219→203，DSP 244。
本轮已完成独立 `flicker_group64reg_fpga` 全板构建尝试：综合通过，布局
失败，剩余实例需要 14534 Slice、可用位置 13805；未布线或安装位流。
详细日志保存在 `results/20260930/physical_grouped_registers/`。后续不能
把该寄存器版列为可烧录设计。紧凑记录与分布式 RAM 候选随后已通过 HLS/
RTL：mode 2=3414 拍，FF=70003，LUT=37907；它的全板物理验证仍待做。

本轮另外验证裁剪合并工作集末尾空子块：固定从像素 0 开始，最后一个有效
子块后停止，不取消存储依赖。变起始地址的首个实验导致 II=60，保留为
失败；固定零起点版本的四个 evaluator 均 II=1，调用延迟为 133–181 拍。
这与原固定 64 像素的 181 拍相比只在尾部有空子块时有效。实际三 Tile
mode 2 RTL 周期 3442→3403，再减 1.13%，不能直接换算为毫秒收益。

## 引入顺序与独立验收

1. **先使已验证的工作集合并真正落到器件。** 分别检查全板资源、拥塞、
   渲染路径 setup/hold 和原厂共享时钟。若 FF 布局受限，比较已有 BRAM
   参数版本，而非降低验证要求或直接宣布 29.19% 实板加速。
2. **继续填满有效像素流水。** 本轮裁剪尾部空块；后续对多个独立 Tile
   上下文交错执行，使用额外状态/队列隐藏流水填充。按像素保持顺序，
   测输入等待、输出背压、有效计算拍数。资源服务于忙碌率与帧延迟。
3. **按 GSCore §4.1 加形状感知粗筛候选。** 对跨多个 Tile 且长短轴比
   超过阈值的高斯才增加 OBB/SAT 测试；论文阈值为 2。先用本场景统计
   额外测试成本和减少的候选数，再决定放 CPU 生成列表或 FPGA 入口。
   与现有 CAT 可能剔除同一批候选，收益不能相加；先验证组合的实际净收益。
4. **再做 FLICKER 混合精度 CTU 与额外并行。** 论文保留 FP16 坐标差，
   在后续测试算术使用 FP8。不能把整条颜色累积随意改成 INT8。当前
   CTU II=8，先确认其背压/供数是否限制已优化 VRU，再增加 PRTU 并行或
   用低精度释放算术资源。最终 RGB 画质与速度同时报告。
5. **投影与分层排序属于下一层。** ARM 投影当前约 7.61 ms，独立排序
   约 2.42 ms。GSCore 分层排序先分深度段、再按需精排，并和渲染重叠，
   不是完全不排序。它需要硬件完成/提前终止反馈及队列接口，因此优先级
   低于约 26.67 ms 的 FPGA 服务段。硬件迁移投影时也必须计入交接成本。

额外 VRU 不直接从四路翻倍为八路：当前每个 evaluator 用 42 DSP；仅增加
四个相同 evaluator 就多用 168 DSP，超过目前全板 252/400 的剩余 148。
这个算术只用于排除直接复制，不能代替新架构综合。可考虑共享几何计算、
局部并行或更低成本算术后再扩路数；LUT/FF/BRAM/布线也需要一起核验。

所有机制独立保留开关和旧版。16k 预览作为速度路线、32k 作为质量对照，
相同相机、画幅、点集和模式配对比较。离线阶段报告 C/RTL 一致性、周期与
资源；板卡恢复后报告相机到完整 RGB 的平均/P95/P99、分阶段耗时、PSNR/
SSIM及实际图像。当前实板基线仍为完整 32k 平均 45.212 ms，历史 16k
31.932 ms；两者不是同版本、同质量配置。本轮视频到首帧和功耗均未测。
