# FLK0：三个架构问题的实板验收

验证日期：2026-09-27。唯一论文主线为 [FLICKER DATE 2026](https://arxiv.org/abs/2603.01158)。本版本关闭 CAT，先建立 FPGA 完整求值基线；不包含 NPU 运算。

## 实现范围与正确性

- CPU 只打包已投影、已排序的高斯参数并提交块描述符。FPGA 实际执行 power、exp、alpha 阈值、提前终止、颜色与透射率累积和背景。逐像素命令已删除。
- 输入通过 SDK 成块进入 PL-DDR，FPGA 原生 512 位 DMA 读取。每帧 30 个任务，每任务 8 Tile；参数按 Tile 重复，尚未实现论文聚类访问。
- 两缓冲和一运行一排队描述符保持所有权，ACK 后启动后续任务。上传/读回与计算交叠，原始状态时间线可复核。不是零拷贝。
- 板卡 BOOT 已从 GSB1 更新为 FLK0；旧 BOOT 已本地/板端备份。网络重启 ID 为 `45e34152-3dbe-4c68-8678-823e00272712`。
- 三个真实 Tile，以及两个完整模型视角各 240 Tile / 983,040 B 原始输出，与电脑端 HLS C FP16 golden 全部逐字节一致；输出前后保护区通过。Golden 未上传板卡。旧加法器和 15 次 SDK 块回读回归通过。
- 万点和两个完整模型的 serial/pipeline 各 1 预热 + 3 次测量，重复输出一致且全部 bit-exact FP16。CPU FP32 对官方严格门槛通过；FP16 对官方严格门槛失败，见下表。

## 资源与时序

- 布线后整板：44,509 LUT、67,398 FF、157 RAMB36 + 19 RAMB18、61 DSP。FLK0 子系统：5,951 LUT、14,108 FF、7 RAMB18、45 DSP；其中渲染核 3,249 LUT、6,166 FF、7 RAMB18、45 DSP。使用布线层级报告，不能与早期 HLS 估计混列。
- 渲染和 DMA 时钟约束 200 MHz；涉及新模块路径 setup 最差 +0.111 ns、hold +0.055 ns。整板 setup WNS +0.030 ns、hold +0.029 ns，均零失败端点。
- 整板仍有原有 AI 时钟两处脉宽失败，WPWS -0.409 ns；并有原厂 SDI GTX 检查在原始厂商 hook 中关闭，约束与旧平台逐字节相同。本次没有增加豁免，组合环路为零。不能称整板时序全面关闭或验证 NPU/SDI 可靠性。
- 功耗、温度漂移与长时间稳定性：功耗未测；本节三次重复不证明长期可靠性。后续单独保存连续运行证据。
