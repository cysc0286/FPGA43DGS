# 第一次 3DGS FPGA 迁移验证

验证日期：2026-09-25。板卡：悟净 30TAI Lite。

**结论：有序 alpha 合成模块已在真实 FPGA 上运行，数值验证通过；当前逐条寄存器传输版本没有性能加速，整板时序仍未验收。**

本轮只迁移颜色累加、透射率更新、提前终止和背景合成。投影、排序及高斯求值不在本模块内；测试输入的 alpha 在电脑上离线生成。尚未把该模块接成整帧在线 3DGS 渲染器。没有开展训练、WSR 或 NPU 渲染。

真实输入沿用冻结的官方 scene/camera/tile：train 模型 iteration 7000，camera 0，640×356 图像中的 Tile (20,10)，原点 (320,160)，每像素对应 5,953 个有序 Gaussian 候选。通过 alpha 阈值的像素–Gaussian 对共 81,789；另有 256 次 CLEAR 和 256 次 BACKGROUND，总计 82,301 条真实场景命令。提前终止后的命令仍提交，用于验证忽略后续贡献的行为；这不是已优化工作量。

原 CPU 基线门槛保持不变：RGB 最大绝对误差 ≤1e-4、均值 ≤1e-5，T 最大绝对误差 ≤1e-5，最后贡献者索引精确相等。定点格式、舍入规则和命令语义见 [README](README.md)。上板程序只接收输入和源码，预期输出留在电脑端独立比较。

## 本轮性能指标与实测

固定输入已经驻留内存；计时排除 SDK 打开、文本解析、文件读写、SSH 和校验哈希。FPGA 主机计时包含每条命令的寄存器写入、完成轮询、最终像素读回。CPU 与 FPGA 使用相同命令流、相同 C++ 源码、GNU C++17 -O2。CPU 配对测量在新 FPGA 镜像启动后进行。

| 指标 | ARM 同阶段参考 | FPGA 寄存器版本 |
|---|---:|---:|
| 预热次数 | 1 | 1 |
| 测量次数 | 20 | 5 |
| 平均 Tile 耗时 | 9.110116 ms | 289.3798 ms |
| 中位数 | 9.06241 ms | 289.374 ms |
| 最小～最大 | 9.01786～9.33955 ms | 289.285～289.449 ms |
| 最终像素输出 | 256 | 256 |
| 输出一致性 | 全部重复一致 | 全部重复一致 |

同阶段加速比定义为 `CPU耗时 / FPGA主机可见耗时`，本轮为 **0.03148×**，即 FPGA 版本约慢 **31.76 倍**。这是当前控制/传输方式的负结果，不能改用不含通信的周期数宣称已经加速。

硬件实际读回的有效工作周期为 **545,559**，与 RTL 仿真一致。按实现报告中的 100 MHz 时钟换算为 **5.45559 ms**，仅覆盖核心工作的周期，不是独立仪器测量的时间。有效累加 15 周期，提前终止判定 6 周期，跳过/CLEAR 3 周期，背景合成 12 周期；这些计数包含捕获与完成边沿，不包含命令间空闲。

每 Tile 有 576,107 次寄存器写、至少 82,301 次完成寄存器读，以及 2,304 次最终状态/周期读。主机总时间减去核心有效时间约 283.92 ms；这部分合并了供数、控制、轮询、空闲、读回和系统调度，尚未进一步拆分实测。它说明下一轮应优先做批量缓冲与 DMA，而不是仅增加算术并行度。

原始 CPU Tile renderer 约 55 ms 的结果还包含高斯求值，与本表 9.11 ms 的合成阶段范围不同；不得互换分母。当前样本量不用于宣称稳定的 P95/P99、整帧 FPS 或功耗收益。

## 后续评价标准

下一轮只做一个增量：以批量任务缓冲/DMA 替换逐条寄存器传输，继续用同一份 Golden 和原有门槛检查正确性，再测同阶段主机总耗时。批量传输必须额外验证长度、尾包、背压、缓冲所有权与缓存一致性。

整帧闭环完成后，再评价固定模型/相机/分辨率下的画质 PSNR/SSIM/LPIPS、camera 提交至 framebuffer 完成的平均/P95/P99 延迟、持续 FPS、DDR 带宽、峰值内存，以及明确测量范围的功率和每帧能耗。模块周期、Tile 回放和论文公布 FPS 均不得替代整帧实测。
