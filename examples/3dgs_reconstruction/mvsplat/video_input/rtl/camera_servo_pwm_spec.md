# 摄像头双轴舵机 PWM 合同

状态：本机 RTL 仿真通过。已生成隔离的顶层接线候选并找到原理图球位；接口电压矛盾尚未解决，未生成可上板固件。

## 电机与接线

依据亚博官方 25KG 舵机资料，YB-P25M 是 PWM 定位舵机，工作电压 6.0–7.4 V，标准行程 180°，500–2500 µs 对应全行程。该控制器不用于连续旋转舵机或步进电机。

依据用户补充的完整原理图 `JFMQL30TAI_LITE.pdf`，原接法 3/5 脚实际进入 Bank 13，供电图为 VCC1V8，与接口页的 3.3 V 说明冲突。用户已同意替换为水平 J17 23 脚 HR_IO13_1P / AE13、俯仰 21 脚 HR_IO13_2P / W13。这两路实际属于 Bank 12，原理图供电为 VCC3V3，候选采用 LVCMOS33。2 脚仍为公共地。上述为排针物理编号，不是 Linux GPIO line offset。换线须先断开舵机外部电源；电机电源不进入 GPIO。实物换线和信号电压仍须核验。

## 接口与时钟

模块 `camera_servo_pwm` 使用同一时钟域的原生合并地址/数据寄存器总线，不是 AXI4-Lite。写请求在 VALID 和 READY 同时为高时接受；读请求最多一笔在途，回压期间返回数据及 VALID 保持。

参数 CLOCK_HZ 默认 100 MHz，必须等于接入时钟，且是 1 MHz 的整数倍；FRAME_US 默认 20000，WATCHDOG_US 默认 500000。水平脉宽默认限制 500–2500 µs，俯仰独立限制 1000–2000 µs。用户确认俯仰已于 1500 µs 回中安装、相机水平，因此按厂商标称映射限制为 ±45°；不以未实测的舵机实际精度作保证。异步低有效复位，平台负责同步释放。复位后两输出禁用，心跳过期。

## 寄存器

- 0x00 只读 ID 0x53525631；0x04 只读 ABI 2；0x08 时钟 Hz；0x0c 周期 µs。
- 0x10 可写使能，bit0 水平、bit1 俯仰。写入使能会先停脉冲，再于完整帧边界使能；写 0 立即禁用。
- 0x14/0x18 可写水平/俯仰脉宽，单位 µs；输入先按完整 32 位值分别限幅，再保存为 16 位。默认 1500；俯仰即使收到 0 或 0xffffffff 也只会锁存 1000 或 2000。
- 0x1c 任意写值刷新心跳；0x20 状态：bit8 过期、bit5:4 请求使能、bit1:0 当前帧使能。
- 0x24 帧计数；0x28/0x2c 当前帧脉宽；0x30 心跳超时 µs。
- 0x34 水平限位；0x38 俯仰限位：高 16 位为上限，低 16 位为下限。主机确认限位与标定配置一致后才允许写入。

## 时序行为

每 20 ms 开始一帧，同步锁存两轴脉宽；帧中写脉宽从下一帧生效，避免产生意外长脉冲。脉冲高电平时间独立设置；使能、复位和看门狗可以截断脉冲以停止输出。关闭 PWM 仅表示不再发送位置命令，不等同于切断舵机供电或机械急停。

示意：一帧先输出 1500 µs 高电平，其余 18500 µs 为低电平；下一帧才采纳新目标。主机默认每 20 ms 最多改变 2 µs，并周期刷新心跳；首个 1500 µs 可能使舵机从未知位置回中，首次应卸下舵盘或确认不会碰撞。

## 验证范围

`tb_camera_servo_pwm.v` 使用 10 MHz 时钟验证十拍/µs 分频，覆盖两轴不同脉宽、20 ms 周期、整帧更新、32 位越界请求、禁用和重新使能、心跳超时与恢复、复位、读回压。参数默认值为 100 MHz；正式平台必须重新核对实际频率。

Python 控制器默认 dry-run，只接受经 ID/ABI/周期和双轴限幅校验的 UIO 映射，拒绝猜测 GPIO 编号或直接使用 /dev/mem。软件在写 MMIO 前拒绝越界俯仰命令，RTL 独立饱和限幅。异常退出尝试关闭输出，进程被强杀时由硬件看门狗停止 PWM。

## 集成边界

必须在候选平台中接出 `camera_pan_pwm`、`camera_tilt_pwm`，应用已同意的 23/21 脚候选约束，并提供与硬件匹配的控制接口。不得把有争议的 AC21/AE20 配成 LVCMOS33。现有冻结平台无这两路顶层端口，因此不能直接运行本机程序来驱动舵机。候选窗口尚未安装，未覆盖冻结 BOOT。

补充候选原生总线路由 `camera_servo_bus.v`：新分配偏移 0x300–0x33f，匹配现有 ICraft 原生地址编码后为 0x400c0300–0x400c033f；这是设计分配，不是已安装接口。其他地址完整透传至原 adder_top，读响应锁定目标至主机消费，延迟及回压时不能切换所有权。与原数据/DMA总线无连接。该候选完成 18 项 RTL 检查；顶层覆盖文件尚未完成整板编译、引脚约束、时序或上板。Python UIO 程序仍只作为可选接口候选，实际采用原生 SDK 路由时需要相应控制适配。
