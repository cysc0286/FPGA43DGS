# 残余黑色条纹：邻近高斯归并

## 原因与范围

上一轮保留 59,445 点，只补偿删点后的平均覆盖面积。它没有保留被删邻点的颜色、透明度和实际空间分布。规则抽样会留下重复间距；对于细长高斯，仅扩大面积也可能在短轴方向留下条纹。多组独立预测和角度硬切换仍是另一类接缝来源，本轮没有将这些问题宣称全部解决。

使用原六组游戏视频上下文、原权重和相机旋转，复用上一轮存下的完整 CPU 高斯，逐项比较。没有新增网络推理、训练、目标图像监督、图像后期补画或 FPGA 位流修改。目标帧参与过旋转登记和方案选择，因此仅属于开发验证，不能当独立测试；本轮没有新增 NPU 或 FPGA 实板结果。

## 默认候选的方法

1. **仍有界取样。** 保留原角度归属和点预算；仅在旧抽样清空充分支持的整行／列时，启用已有二维备选。点数不会因归并增加。
2. **在实际源视角分组。** 将角度归属范围内的完整高斯投影回自己的源相机，以最近的保留中心归组。限定同一源视角，不跨帧对、不跨方向融合未知深度；本组数据最大归并距离约 2.1684 个源图像像素。
3. **保留邻点信息。** 以透明度乘投影协方差行列式的平方根表示高斯的屏幕积分权重，汇总投影中心、协方差和 SH 颜色。协方差包括各点自身形状，也包括点与点之间的位置差异。由积分权重与新面积恢复峰值透明度，避免一律沿用某一个被选中点的透明度。
4. **接回原接口。** 用加权预测深度将结果转换回世界坐标，维持原世界协方差／SH ABI。源视角没有裁减时逐位保留原参数；零积分权重的组保留原字段。保留点即使同址，也强制拥有自己的源成员，防止空组。

这是对有序 alpha 合成的近似，不是无损等价。峰值透明度上限沿用 0.99，并显式记录裁剪：本场景有 6,534 个归并组触及该上限。空间平均可能模糊纹理；纯旋转的深度不可观测性和跨组不一致没有因此消失。

## 六视角画质与消融

分辨率固定 128×128，同一独立 NumPy SH3 数值参考渲染器与 SSIM 定义，数值取六视角算术平均。

| 方法 | 最终点数 | 平均 PSNR / SSIM |
|---|---:|---:|
| 上轮面积补偿 | 59,445 | 19.6757 dB / 0.620833 |
| 局部间距补偿，强度 1 | 59,445 | 20.4754 dB / 0.631570 |
| **邻近高斯归并** | **59,445** | **21.0214 dB / 0.652900** |

六个方向 PSNR 均提高。SSIM 有四个方向提高，两个方向分别下降约 0.00504 和 0.01220，不能称“所有指标、所有方向都提高”。黑纹明显的第 529 帧由 19.2148 dB / 0.728995 改善到 22.3724 dB / 0.850862。

进一步扩大局部滤波和增加预算均作了对照，未选为默认：

| 对照 | 点数 | 平均 PSNR / SSIM |
|---|---:|---:|
| 局部间距补偿，强度 2 | 59,445 | 21.0480 dB / 0.631711 |
| 局部间距补偿，强度 4 | 59,445 | 21.7568 dB / 0.625325 |
| 总预算提高到 98,304 | 83,087 | 19.5892 dB / 0.628711 |

强滤波虽然 PSNR 更高，细节结构与直观看感不及归并；增加点数也不能自动保证抽样分布和画质更好。半强度局部补偿为 20.1113 dB / 0.628538，日志同样保留。

## 条纹回归、数值与工作量

- 将颜色改为统一常量，在相同透明度、排序和合成流程下，比较候选与未裁减有效点场景的覆盖分布，隔离真实纹理。问题视角中央 96×96 区域的相对高频覆盖误差 RMS 从 0.076544 降至 0.041735，约降低 45.5%；预先采用的 0.05 门槛由失败转为通过。条纹仍非完全消失。
- 不能用“最终透射率应为零”作为正确性要求：预训练输出本身存在低透明度，未裁减场景也有明显剩余透射率。初版绝对透射率探针同时拒绝两者，已排除该错误判据，改用上述相对高频误差。
- 真实 `generate_ring` 默认入口与原型输出逐字段对齐；冻结导出行格式的协方差分解／重建最大相对 Frobenius 误差约 4.78×10^-7，无特征值裁剪。最终哈希、首帧前不落盘、之后归档和回读校验均正常。
- 六帧参考渲染的候选求值从 34,189,312 降至 32,736,612，减少约 4.25%。这是软件参考的工作量计数，不是 FPGA 加速比或实测 DDR 流量。
- 最终点数和字段格式不变，高斯数组有效负载仍为 20,924,640 字节；源视角归并新增临时数组和 CPU 开销。板端 PSS、场景准备时间、换视角时延和功耗未测。无新增综合／布线，因此 FPGA 资源报告未更新。
- 本轮实际合并入口一次本机耗时约 1.514 秒，包含读取已存张量、校验与归并；测量期间有其他本地测试并行运行，既非公平配对计时，也非板端成绩，不据此宣称总时延改善。
- 110 项回归通过，覆盖投影积分权重与一二阶矩、恒定颜色保持、零透明度、同址代表点、输入不变、旧策略回退、归档、流式生命周期、网页与渲染 ABI。

## 使用和回退
