# 相邻区域过渡融合验证

## 问题和实现

上轮邻近高斯归并缓解了删点条纹，但来源仍按最近相机光轴硬切换。两组独立预测的亮度、颜色与深度并不完全一致，归属边界因而出现明显台阶。本轮先在一个固定透视视角复现接缝，排除了全景展示拼接是唯一原因的解释，再修改高斯合并过程。

`blending.py` 使用所有上下文相机的真实旋转和裁剪后内参判断观测范围。在实际重叠的方向，按相对最佳光轴的角度差构造 smoothstep 权重，再乘源图像边缘置信度，归一化后由各来源共同贡献；不再在边界立即删掉另一来源。所选角度差参数为 8°，不是承诺所有方向都有几何宽度恰好 8° 的过渡带；边缘范围为归一化图像宽高的 4%。极小权重低于 0.001 时剔除，随后重新归一化。

透明度按峰值光学厚度分配，而非直接对 alpha 做线性平均。对于位置重合、颜色相同且权重和为一的样本，它保持峰值透射率；一般高斯足迹和多深度有序合成仍是近似，不能称为无损。峰值沿用 0.99 上限。每个源视角先分配贡献，再按已有有界抽样和邻近高斯归并收敛到预算，最终仍汇成一个高斯场景。没有把原视频照片贴到结果上，也没有额外训练、补画缺失方向或跨组拟合不可观测深度。

## 同输入开发验证

复用原六组、十二张上下文产生的完整 CPU 高斯，不重新运行网络；相机、权重、分辨率 128×128、六个评测朝向、独立 NumPy SH3 有序 alpha 参考渲染器和质量指标定义不变。评测帧参与过旋转登记及候选选择，因此这些数值属于开发验证，不是独立测试成绩，也不是新 NPU／FPGA 板端结果。

| 方案 | 平均 PSNR / SSIM | 实际保留点数 |
|---|---:|---:|
| 原角度硬切换与邻近归并 | 21.0214 dB / 0.652900 | 59,445 |
| **8°角度差过渡与边缘置信度** | **21.9927 dB / 0.667197** | **65,532** |

六个方向 PSNR 均提高；SSIM 四个提高、两个分别降低约 0.00370 和 0.01241。黑纹明显的第 529 帧 PSNR 从 22.3724 升至 24.8586 dB，SSIM 从 0.850862 降至 0.838456。融合可以平滑部分纹理，不能把均值提高说成每个方向的所有指标均提高。

配置预算相同，但实际保留点数不同；这些整体收益包含重叠点保留和权重变化的共同影响，不能作为固定实际点数下仅改变渐变函数的独立消融结论。

主接缝探针固定在相对最早上下文相机的 -20.21° 视角，不经过全景重投影。取中央 64 行，在原来源边界两侧各三像素求平均 RGB 的欧氏距离（RGB 范围 0—1）：

| 测量 | 修改前 | 修改后 |
|---|---:|---:|
| 平均边界跳变 | 0.284817 | 0.063051 |
| P95 边界跳变 | 0.526156 | 0.198355 |

平均跳变降低约 77.9%，预设均值不大于 0.12 的探针由失败转为通过。该探针只衡量已复现的这条接缝，不等同全景无缝或通用画质指标。全景另由同一合并场景的 36 个固定中心透视方向重投影展示；新旧均使用相同的展示采样，未覆盖的约 +26°—+35° 方向仍有黑色缺口，不用过渡融合伪造覆盖。

有限消融还比较了下列方案：

| 对照 | 平均 PSNR / SSIM | 平均接缝跳变 |
|---|---:|---:|
| 仅真实视锥硬归属 | 21.2119 dB / 0.652672 | 0.275550 |
| 4°过渡与边缘置信度 | 21.3843 dB / 0.663474 | 0.083110 |
| 8°过渡但去掉边缘置信度 | 21.4573 dB / 0.661913 | 0.062296 |

采用 8°加边缘置信度，是因为六视角整体质量更好；没有只选择接缝探针最小的一组。

## 代价、接口与回退

- 总预算仍为 65,536；实际点数从 59,445 增至 65,532，约增加 10.2%。高斯数组有效负载从 20,924,640 增至 23,067,264 字节。与原来只保留唯一来源相比，重叠保留会增加存储与渲染工作。
- 六视角候选求值合计从 32,736,612 增至 42,293,343，约增加 29.2%。这是软件参考的求值计数，不能等同于板端时延增加 29.2%。板端峰值 PSS、场景准备及换视角耗时尚未测量。
- 真实 `generate_ring` 输出与独立原型逐字段对齐。冻结渲染 ABI 的协方差分解／重建最大相对 Frobenius 误差约 4.78×10^-7，无特征值裁剪。六次流式消费、首帧前不写中间 NPZ、之后归档哈希及回读校验均通过。
- 本机生产回放一次合并约 2.93 秒，包含已存张量读取及校验；这不是真实网络前向或公平配对性能测试，不能代入板端总时间。
- `prepare_ring_scene(..., transition_degrees=8.)` 是本地场景准备默认候选；设为 `0.` 恢复上轮硬切换。底层 `generate_ring` 为兼容独立调用仍默认 `0.`，新行为需显式传 `8.`。`reduction='footprint'` 和原始删点回退仍保留，恢复历史结果时也应设 `transition_degrees=0.`。
- 新模块已列入核心源码清单。FPGA RTL、位流、NPU 子图、单组生成和网页协议未改，板端服务尚未替换；没有新的综合、资源、功耗或实板速度成绩。
- 116 项本地回归覆盖接缝权重、真实视锥与未观测方向、透明度分配、重复来源、源数组不变、流式合并、旧模式回退、导出格式、归档和网页协调。

私有视频、张量、图像与回放脚本全部留在仓库外 `private_media/20261112_ring_uniformity`，永不提交。最终证据是 `quality_transition_production.json`，对照图为 `transition_before_after.png`、`transition_contact_sheet.png` 和 `panorama_transition/comparison_360.png`。原候选与全部消融仍保留。
