# 历史归档，不是运行入口

`history_20261009/` 是纳入 Git 的历史源码、实测证据和整理前文档包。
每个 ZIP 保留仓库原始相对路径；`index.json` 逐文件记录大小与 SHA256。
失败实验、负收益和旧画质记录均保留。

`local_workspace_20261009/` 只存本机原始运行目录和未纳入 Git 的实验文件，
不上传 GitHub，不进入主线源码包。它不是已经经过逐文件归档审计的 ZIP。
