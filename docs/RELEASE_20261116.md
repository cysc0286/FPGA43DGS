## 画质与调用流程

1. `video_input/ring_balance.py`根据真实旋转与裁剪后的视野，在有界候选中兼顾水平覆盖和各扇区支持；不将拍摄时间直接当角度。保留legacy选组回退及实际覆盖不足记录。
2. `gaussian_generation/sampling.py`在点数预算内检查二维采样空洞，并支持邻近高斯矩归并，减少预算裁减造成的条纹；缺失方向不补画，不恢复不可观测深度。
3. `gaussian_generation/blending.py`按真实视锥、方向角差和图像边缘置信度构造过渡权重，再以光学厚度分配透明度。各组最终汇入同一个高斯场景，之后统一排序、渲染。
4. `gaussian_generation/appearance.py`用原输入上下文和常驻渲染器的线性RGB/覆盖率构造共享低频残差，仅修正SH的DC颜色项。修正发生在首次场景准备中，不在网页上贴入原图；`--ring-appearance-strength 0`关闭颜色修正。
5. `initialize/ring.py`负责上述步骤的顺序、内容哈希、场景发布和延后归档；`rendering/resident_runtime.py`提供真实线性帧接口，`web/camera_ui.py`将同一配置传入直接入口，避免网页与命令行采用不同流程。

相关机制、来源论文、开发验证和代价详见`gaussian_generation/RING_*VALIDATION_20261112.md`与`RING_SEAM_LITERATURE_20261112.md`。既有六视角CPU参考回放中，过渡融合PSNR/SSIM为21.9927dB/0.667197，共享颜色残差为23.950285dB/0.693383；它们是2026-11-12开发验证，不能作为本轮FPGA实测或独立测试成绩。颜色修正增加上下文渲染工作，过渡融合保留更多重叠贡献，不能只凭画质改善声称总耗时下降。
