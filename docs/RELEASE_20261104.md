## 核心源码包

使用 tools/package_core.py 创建，保持六部分目录、NPU/FPGA 主线、部署脚本和公共说明；并从冻结 manifest 逐项核验、打包 render_main 的 RTL ROM、BOOT.bin、位流及配套报告。
ZIP 内逐文件记录 SHA256，压缩后不得超过 200 MiB。用户录像、输入帧、场景、权重、ICraft SDK、Python 环境和个人部署凭证不包含在内。ZIP 里的 BOOT/位流是冻结资产副本，不表示本轮重刷或新增板端验收。
此包含 FPGA RTL/HLS 与板端部署素材，但不含可直接打开的完整原厂 Vivado 工程快照（XPR/Block Design/XSA/XDC）；整板重建仍需供应方平台文件和配套工具。
